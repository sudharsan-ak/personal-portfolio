# Project: Resume Tailoring Workflow

## Overview
A privacy-first AI workflow that turns a master resume into a role-specific LaTeX PDF through a 7-stage pipeline, using local RAG for evidence retrieval and an autopilot mode with one human checkpoint. All retrieval runs fully offline with no API key required.

## Technologies
TypeScript, PowerShell, LaTeX, Node.js, MCP, RAG, Vector Search

## Key Features & Achievements
- Local RAG pipeline for semantic evidence retrieval, fully offline, no API key
- MCP server fetches full job descriptions from any ATS URL via headless browser, no copy-paste
- Autopilot mode with one human checkpoint plus a privacy-check script before every commit
- 21 recruiter callbacks and counting, from companies including Google, Visa, Chime, and Bloomberg, all tracked and verified, not fabricated
